เว็บเกมสำหรับทบทวนเนื้อหา 12 บท แยกจากระบบสอบออนไลน์ ใช้ GitHub + Netlify (Functions + Blobs) ไม่ต้องมีฐานข้อมูลภายนอก

## โหมดการเล่น
1. **เกมสด (แบบ Kahoot)**: อาจารย์เปิด `/host.html` บนจอโปรเจกเตอร์ เลือกบท ประเภทคำถาม จำนวนข้อ และเวลาต่อข้อ ระบบจะสร้าง PIN 6 หลัก นักศึกษาเข้าเมนู “เกมสด” แล้วกรอก PIN
   - คะแนนต่อข้อ 500–1,000 ตามความเร็ว บวกโบนัสตอบถูกต่อเนื่องข้อละ 100 (สูงสุด 500) จับเวลาที่เซิร์ฟเวอร์
   - เฉลยอัตโนมัติเมื่อหมดเวลาหรือทุกคนตอบครบ แสดงคำอธิบายและเลขหน้า ตารางคะแนน และโพเดียมตอนจบ
   - คลิกชื่อในห้องรอเพื่อนำผู้เล่นออก ดาวน์โหลดผลเป็น CSV ได้
2. **ฝึกคนเดียว**: แผนที่ 12 บท บทละ 2–4 ด่าน (ตอบคำถาม, ทายชื่อท่าจากภาพ, จับคู่, เรียงลำดับ)
   - ได้ 3 ดาวเมื่อถูก 90% ขึ้นไป, 2 ดาวเมื่อ 70%, 1 ดาวเมื่อ 50% ระบบเก็บผลที่ดีที่สุดของแต่ละด่าน
   - เลเวลขึ้นตามจำนวนดาวรวม (สูงสุด 111 ดาว): นักมวยฝึกหัด → นักมวยดาวรุ่ง (10) → นักมวยมือรอง (25) → นักมวยมือหนึ่ง (45) → แชมป์เวที (70) → ปรมาจารย์มวยไทย (95)
3. **อันดับรวม**: เรียงตามคะแนนสะสม (ผลดีที่สุดของทุกด่านรวมกัน) แสดงชื่อเล่นและรหัสนักศึกษา 3 ตัวท้ายเท่านั้น

ผู้เล่นใช้ **รหัสนักศึกษา + ชื่อเล่น** ระบบจำไว้ในเครื่อง ถ้าใช้รหัสเดิม ดาวจะสะสมต่อแม้เปลี่ยนเครื่อง

## หน้าผู้ดูแล
- เมนู **อาจารย์** (มุมขวาบน) หรือ `/admin.html`
- รหัสผ่านเริ่มต้น: `Yongyut123456789` ในโค้ดเก็บไว้เป็นค่า SHA-256 ไม่ใช่ตัวรหัสจริง
- เปลี่ยนรหัสได้โดยตั้ง Environment variable `ADMIN_PASSWORD` ใน Netlify แล้ว Deploy ใหม่
- แท็บ **ความก้าวหน้าผู้เล่น**: ตารางดาวและคะแนนรายคน ค้นหาได้ ดาวน์โหลด CSV แยกดาวรายด่าน และล้างผลรายคนได้
- แท็บ **ประวัติเกมสด**: รายการห้องที่เคยเปิด เปิดจอต่อได้ และดาวน์โหลด CSV ของแต่ละห้อง
- แท็บ **จัดการข้อมูล**: ล้างผลทั้งหมดเมื่อขึ้นภาคเรียนใหม่ ต้องพิมพ์ยืนยัน

## ติดตั้ง (GitHub + Netlify)
1. สร้าง repository ใหม่บน GitHub เช่น `muaythai-game` แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ให้ `netlify.toml` อยู่ที่ระดับบนสุด)
2. ที่ Netlify: **Add new site → Import an existing project → GitHub** แล้วเลือก repository
3. ไม่ต้องแก้ค่า Build เพราะ `netlify.toml` กำหนดไว้แล้ว (publish = `public`, functions = `netlify/functions`) จากนั้นกด **Deploy**
4. (แนะนำ) ตั้งชื่อเว็บใน Site configuration → Change site name เช่น `032437-game` จะได้ `https://032437-game.netlify.app`
5. ไม่บังคับ: ตั้ง `ADMIN_PASSWORD` เพื่อเปลี่ยนรหัสผ่าน และ `TOKEN_SECRET` (ข้อความสุ่มยาว) ถ้าไม่ตั้ง ระบบจะสุ่มกุญแจเองแล้วเก็บใน Netlify Blobs

Netlify Blobs เปิดใช้อัตโนมัติ ข้อมูลเก็บใน store ชื่อ `muaythai-game` แยกจากระบบสอบ

## โควตา Netlify แบบฟรี
ระหว่างเกมสด นักศึกษาแต่ละคนจะถามสถานะทุก 2–3 วินาที
- ตัวอย่าง: 40 คน เล่น 15 นาที ใช้ประมาณ 15,000–18,000 ครั้ง
- แผนฟรีให้ Functions ประมาณ 125,000 ครั้งต่อเดือน จึงเล่นเกมสดได้ราว 6–7 รอบต่อเดือน
- โหมดฝึกคนเดียวใช้น้อยมาก (ไม่กี่ครั้งต่อด่าน)

## ทดสอบในเครื่อง
```bash
npm test          # ทดสอบตรรกะทั้งหมด (ฝึก, อันดับ, เกมสด, ผู้ดูแล)
npm run dev       # เปิด http://localhost:8888 (ใช้ที่เก็บข้อมูลจำลองในหน่วยความจำ)
```

## โครงสร้างไฟล์
```
netlify.toml                      ตั้งค่า Netlify และ security headers
netlify/functions/api.mjs         จุดเข้า API (/api/*)
netlify/functions/lib/game.mjs    ตรรกะเกมทั้งหมด
netlify/functions/lib/data.mjs    คลังคำถาม ภาพ ชุดจับคู่ และชุดเรียงลำดับ (มีเฉลย อยู่ฝั่งเซิร์ฟเวอร์)
public/                           หน้าเว็บ: index, play (เกมสด), host (จออาจารย์), practice, board, admin
public/img/                       ภาพท่าจากเอกสาร (ตั้งชื่อไฟล์เป็นเลข ไม่บอกเฉลย)
tests/                            ชุดทดสอบและเซิร์ฟเวอร์ทดสอบ
```

แก้ไขหรือเพิ่มคำถามได้ที่ `data.mjs` (คำถามแต่ละข้อต้องมี `id, ch, type, q, o, a, exp, page` โดย `a` คือลำดับตัวเลือกที่ถูก เริ่มที่ 0)
